# Jose A. Peña Vega — Urban Studies & Planning

A responsive personal portfolio featuring Bayview–Hunters Point research, civic engagement experience, and developing GIS work.

## Website

This is a static website. No build step or dependencies are required.

- `index.html`: portfolio homepage
- `bayview.html`: Bayview research overview
- `assets/style.css`: responsive layout and typography
- `assets/site.js`: mobile navigation
- `credits.html`: photography and typeface credits

## GitHub Pages

Publish the `main` branch from `/(root)` in **Settings → Pages → Deploy from a branch**. The included `.nojekyll` file makes the static files ready for direct publication. All local links work under either a user site or a project site.

## Updating the portfolio

Edit the HTML files to update the content. Keep images, documents, and other assets in `assets/`. Add the final Bayview paper when it is ready. The GIS certificate is currently listed as expected in early November 2026.

Ubuntu fonts are served locally. Their licence and copyright notice are included in `assets/`. Photography credits are listed on the credits page.
